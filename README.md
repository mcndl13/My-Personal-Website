## Stack

- **React 19 + TypeScript** for the UI
- **Vite** for dev server and builds (`tsc --noEmit` type-checks before every build)
- **Tailwind CSS v4** for styling
- **Vercel** for hosting · designed in **[Figma](https://www.figma.com/design/7ErznmMGAD7OuNgcGEfna9/Portfolio-Website?node-id=100-129&t=txWSWPQmlsY8CNGX-1)**

## Run locally

```bash
cd my-portfolio
npm install
npm run dev       # http://localhost:5173
npm run build     # type-check + production build
```

Requires Node.js 24.
