# Mouhamed — Software Engineer Portfolio

A responsive React and TypeScript portfolio with light/dark mode, project links, experience, skills, and contact information.

## Setup

```bash
npm install
npm run dev
npm run build
```

## Component structure

- `src/components/`: Header, Footer, ThemeToggle, ProjectCard, ProjectVisual, StarChart, SectionHeading.
- `src/sections/`: Hero, Work, Skills, Experience, About, Contact.
- `src/data/portfolio.ts`: all profile information, experience details, projects and skills.
- `src/index.css`: design tokens, light/dark mode, responsive layouts, project illustration styles.
- `public/assets/`: original color portrait and employer logos.

## Content

Profile information, project links, experience, and skills are maintained in `src/data/portfolio.ts`.

The site includes links to GitHub repositories, the MeMantra App Store listing, LinkedIn, and the downloadable résumé.
